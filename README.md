A fast-paced neon cyberpunk survival arcade game built for the [make.fun best-game-01 bounty](https://make.fun/bounty/best-game-01).
Avoid dynamic cyber hazards, collect data cores, trigger shield overcharges, and survive against escalating waves.

- Runs 100% offline in desktop Chrome using modern HTML5 Canvas.
- Fully procedural synth audio synthesized via Web Audio API.
- Polished neon visuals with particle bloom, combo multiplier, and screenshake feedback.
- Clean responsive controls with start, pause, restart, and high-score persistence.
